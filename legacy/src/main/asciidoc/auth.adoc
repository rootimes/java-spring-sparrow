== Authentication API
提供使用者登入與登出的相關 API。

=== 驗證架構說明
本系統採用 **混合式驗證 (Hybrid Authentication)** 架構，同時支援：
**Web 端**：透過 Session (Cookie) 維持登入狀態。
**App 端**：透過 JWT (Token) 進行 stateless 驗證。

=== 使用者登入 (成功)
使用者可以透過電子郵件與密碼進行登入。成功後會回傳 JWT Token，瀏覽器亦會收到 `JSESSIONID` Cookie。
